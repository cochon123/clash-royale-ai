# Clash Royale Policy BC (early)

Early offline behavioral-cloning policy checkpoint. Prefer [policy-bc-v4](https://huggingface.co/Cochon123/clash-royale-policy-bc-v4) for current work.

## Files

- `best_model.pt` — PyTorch checkpoint
- `vocab.json` — card / action vocabulary
- `report.json` — training metrics and metadata
- `training_stages.json` — stage curves for reports
