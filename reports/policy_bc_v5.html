Lessons

  • Training spanned 3 runs and 21 logged epochs before the process died; the HTML stitches the full log, not only the last truncated stages file.
  • Run 1 crashed at the first REINFORCE polish (cuDNN GRU backward under eval). Run 2 reached global epoch 11 with working polish. Run 3 resumed and died again before polish.
  • Best saved weights come from the resume cut (slot@1 ≈ 55%). Controllable style metric feature_l2 improved vs v4.1 (≈1.43 vs ≈1.84).
  • Clock-aware rollouts saturate P(human); the residual AI signature is placement spread (team/opp x_std) more than timing.
  • Alternation-harness P(human) stays near zero — the frozen judge still keys off harness artifacts when turn-taking is forced.
