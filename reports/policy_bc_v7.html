What changed in v7

The v6.1 backbone is frozen. v7 only trains the arena-memory adapter and a residual gate on top of the heatmap prior.

frozen from v6.1
card embeddings + causal GRU
cycle + threat features
card-conditioned slot / zone heads · locked
v7 experiment
16-channel arena-memory raster (τ=2.5–20s)
conv adapter + spatial residual
gated residual added to heatmap prior

The memory remembers decayed action locations only. It cannot see troops, health, death, targeting, elixir or pathing — so even if the gate had passed, this would be a placement prior, not arena state.

Lessons and next decision

The honest outcome: the adapter learns to open, not to read.

  • v7 adds a causal 16-channel arena-memory proxy over the frozen v6.1 heatmap prior.
  • The proxy remembers decayed action locations; it does not observe troop movement, death, health, or targeting.
  • Aligned-versus-shuffled memory and adapter-off probes are required before calling the state hypothesis supported.
  • This is an offline placement experiment and is not a live-play readiness signal.
recommended next move
State before scale.

The gain did not survive the shuffled control, so scaling this adapter would multiply capacity, not state. The larger move is a latent arena-state tracker that observes troops, towers and elixir — then chooses among heatmap modes using what is actually on the board.
