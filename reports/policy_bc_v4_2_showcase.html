06 · symmetry augmentation

What mirroring actually changed

Horizontal reflection teaches left/right equivalence while preserving time, card identity, side, elixir, and vertical territory.

original x → 18,000 − x
same y · same action · same target
Training only

33,309 original training battles received mirrored views. Validation and test stayed unmirrored.

Memory-light implementation

Mirrored events share the original event records and lazily transform x, avoiding a second multi-gigabyte replay copy.

What this run cannot prove

Because epoch count, batch size, and sample cap also changed, v4.2 is not a clean mirror-vs-no-mirror ablation.

08 · lessons

What v4.2 taught us

The experiment is valuable precisely because the answer is not “more data automatically wins.”

01 / CAPACITY

The architecture is not the changed variable.

All checkpoints have the same 632,946 parameters. v4.2’s regression points to training protocol and data sampling before model capacity.

02 / BUDGET

Updates matter more than headline sample count.

v4.2 saw 59% more samples per epoch but made 53% fewer optimizer updates than v4.1. Its LR reached zero while validation loss was still improving.

03 / EVIDENCE

Mirroring remains unresolved.

Do a controlled continuation or ablation on one frozen split. Keep sample cap, batch, update count, seed, and schedule identical.

Recommended next experiment: warm-start from v4.2, restore a non-zero learning rate, and match at least v4.1’s ~39.7k optimizer updates. For a clean result, compare mirrored and unmirrored twins on one frozen manifest.
